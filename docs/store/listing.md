## 한국어

**이름:** CurrentVibe

**짧은 설명:** 지금 뜨는 GitHub 저장소를 웨일 사이드바에서 보고, AI에게 분석부터 시키는 프롬프트를 복사하세요.

**상세 설명:**
지금 개발자들 사이에서 뜨는 GitHub 저장소를 웨일 사이드바에서 바로 확인하세요.
새 도구를 발견하면 AI에게 "바로 적용"이 아니라 "분석부터" 시키는 프롬프트를 한 번에 복사할 수 있습니다.

■ 트렌드 한눈에 보기
- Daily · Weekly · Monthly 탭으로 GitHub Trending 순위를 확인합니다.
- 저장소마다 전체 Star 수와 기간 동안 늘어난 Star 수를 함께 보여 줍니다.
- 상위 10개를 먼저 보여 주고, 나머지는 "더 보기"로 펼칩니다.

■ 저장소별 바로 쓰는 버튼
- 저장소 바로가기: 새 탭에서 GitHub 페이지를 엽니다.
- 레포지토리 링크 복사: 저장소 주소를 클립보드에 복사합니다.
- 프롬프트 복사: AI에게 붙여 넣을 분석 프롬프트를 복사합니다.
- 복사하면 화면 아래에 짧은 알림이 떠서 바로 확인할 수 있어요.

■ "분석부터" 시키는 프롬프트
AI가 코드를 바로 고치지 않고 다음 순서로 먼저 정리하게 만듭니다.
1. 요약: 이 저장소가 무엇이고 어떻게 동작하는지
2. 적용 가능 여부: 지금 내 프로젝트와 환경에 맞는지, 그 이유
3. 사용 가능한 환경: 어떤 AI 도구와 환경에서 쓸 수 있는지, 설치 형태(스킬, 플러그인, MCP 서버, 라이브러리 등)
4. 이점: 적용했을 때 얻는 것
5. 적용 방법: 단계 개요, 예상 변경 범위, 단점과 주의할 점
분석이 끝나면 적용할지 먼저 묻고, 승인하기 전까지 아무것도 바꾸지 않습니다.
Claude, ChatGPT, Cursor, Codex 등 어떤 AI 도구에도 붙여 넣어 쓸 수 있습니다.

■ 한국어 · English
오른쪽 위 스위치로 언어를 바꾸면 화면 문구와 프롬프트가 함께 바뀝니다.

■ 개인정보
로그인이나 API 키가 필요 없습니다. github.com/trending 페이지만 읽고, 기기에는 언어 선택만 저장합니다. 개인정보를 수집하거나 외부로 보내지 않습니다.

## English

**Name:** CurrentVibe

**Short description:** See trending GitHub repos in your Whale sidebar and copy a prompt that makes your AI analyze before it applies anything.

**Detailed description:**
See what is trending on GitHub right in your Whale sidebar.
When you find a new tool, copy a prompt that makes your AI analyze it first instead of applying it right away.

■ Trends at a glance
- Daily · Weekly · Monthly tabs for GitHub Trending.
- Total stars and stars gained in the period for each repository.
- The top 10 come first; "Show more" reveals the rest.

■ One-click actions per repository
- Open repository: opens the GitHub page in a new tab.
- Copy repository link: copies the URL to your clipboard.
- Copy prompt: copies an analysis prompt to paste into your AI.
- A short toast confirms each copy.

■ A prompt that analyzes first
The AI reports in this order before touching any code:
1. Summary: what the repository is and how it works
2. Applicability: whether it fits your current project and environment, and why
3. Supported environments: which AI tools and environments it works with, and its install form (skill, plugin, MCP server, library, etc.)
4. Benefits: what you gain by applying it
5. How to apply: outline of steps, expected scope of changes, downsides and cautions
Then it asks whether to apply it and changes nothing until you approve.
Works with any AI tool: Claude, ChatGPT, Cursor, Codex and more.

■ Korean · English
Use the switch at the top right; the UI text and the prompt change together.

■ Privacy
No login or API key needed. The extension only reads github.com/trending and stores only your language choice on your device. It collects no personal data and sends nothing elsewhere.
