## 한국어

**이름:** CurrentVibe

**짧은 설명:** 지금 뜨는 GitHub 저장소를 웨일 사이드바에서 보고, AI에게 분석부터 시키는 프롬프트를 복사하세요.

**상세 설명:**
GitHub Trending 순위를 웨일 사이드바에서 바로 확인하세요.

- Daily · Weekly · Monthly 순위와 기간 동안 늘어난 Star 수를 한눈에 봅니다.
- 저장소마다 열기, 주소 복사, 프롬프트 복사를 한 번에 할 수 있어요.
- "프롬프트 복사"는 AI가 바로 코드를 고치지 않고, 저장소 요약, 적용 가능 여부, 사용 가능한 AI 도구와 환경, 이점, 적용 방법을 먼저 정리한 뒤 적용할지 묻게 만드는 정형화된 프롬프트입니다.
- Claude, ChatGPT, Cursor, Codex 등 어떤 AI 도구에도 붙여 넣어 쓸 수 있어요.
- 한국어와 영어를 전환할 수 있습니다(화면 문구와 프롬프트가 함께 바뀜).

로그인이나 API 키가 필요 없습니다. 이 확장은 github.com/trending 페이지만 읽고, 기기에는 언어 선택만 저장합니다. 개인정보를 수집하거나 외부로 보내지 않습니다.

## English

**Name:** CurrentVibe

**Short description:** See trending GitHub repos in your Whale sidebar and copy a prompt that makes your AI analyze before it applies anything.

**Detailed description:**
Browse GitHub Trending right in the Whale sidebar.

- Daily · Weekly · Monthly rankings with total stars and stars gained in the period.
- Open, copy URL, or copy prompt for each repository in one click.
- "Copy prompt" gives a structured prompt that makes the AI summarize the repo, judge whether it fits your project, list which AI tools and environments it works with, explain the benefits and how to apply it — and then ask before changing anything.
- Works with any AI tool: Claude, ChatGPT, Cursor, Codex and more.
- Switch between Korean and English (UI text and prompt switch together).

No login or API key needed. The extension only reads github.com/trending and stores only your language choice on your device. It collects no personal data and sends nothing elsewhere.
